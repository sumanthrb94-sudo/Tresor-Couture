TRESOR COUTURE — 15 ft x 4 ft signboard (180 x 48 in) — CorelDRAW pack

Open in CorelDRAW: File > Open (or Import) and choose one of:

 1. tresor-couture-signboard-15x4ft-curves.svg   <- RECOMMENDED
    Lettering is converted to curves, so it looks exactly as designed on any
    computer. Panel, frame, emblem and each line of lettering are separate
    objects you can move, recolour or resize.

 2. tresor-couture-signboard-15x4ft-livetext.svg
    Lettering stays as editable text. FIRST install the font:
    double-click CormorantGaramond-Bold.ttf > Install, then restart CorelDRAW.

 3. tresor-couture-signboard-15x4ft.eps
    Same artwork as EPS for sign shops that prefer it (font embedded).

Colours: panel #F5ECDC (cream), frame and lettering #B8893A (gold).
Flat colours only — no glow, gradient or shadow.
emblem.png is the master TC emblem (transparent) if you need to re-link it.
